# Scania R XXL Extended Box — Standalone

Unofficial personal edit for Farming Simulator 25.

## Website
https://Pops2207.github.io/scania-extended-box/

## Download
The website's Download button opens the latest GitHub Release:
https://github.com/Pops2207/scania-extended-box/releases/latest

**Important:** upload `FS25_Scania_R_XXL_Extended_Box_Standalone.zip` (about 76 MB) as a Release asset. The GitHub connector can create website files, but cannot upload this large binary asset directly.

## Installation
1. Download the ZIP asset from Releases.
2. Put it in your FS25 `mods` folder.
3. Keep the original Scania mod if desired, but remove older copies of the Extended Box edit.
4. Enable this mod and FS25_UniversalAutoload in-game.

Package validated; in-game testing is still needed. Not an official GIANTS Software or ModHub release.
