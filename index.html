What's included

  • Separate in-game shop entry: Scania R XXL - Extended Box.
  • Extended Box Body configuration.
  • Unique vehicle XML and autoload script paths, designed to coexist with the original mod.

Unofficial personal edit. The package has been validated, but the extended body still needs in-game testing.

Installation

  1. Close FS25.
  2. Copy the downloaded ZIP to your FS25 mods folder.
  3. Keep the original Scania ZIP; remove older Extended Box copies.
  4. Enable this mod and FS25_UniversalAutoload.
  5. Choose Scania R XXL - Extended Box in the vehicle shop.
